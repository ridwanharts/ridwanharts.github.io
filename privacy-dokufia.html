Kebijakan Privasi — DokuFia

Terakhir diperbarui: 14 September 2026

DokuFia adalah aplikasi Android pendamping guru untuk mengelola data siswa, absensi harian, invoice bulanan, profil sekolah, dan tanda tangan digital.

Data yang Dikumpulkan

DokuFia tidak mengirimkan data pribadi pengguna ke server pengembang. Data yang dimasukkan pengguna, termasuk nama siswa, kelas, nama orang tua, alamat, nomor telepon orang tua, data absensi, data invoice, nama guru, profil sekolah, dan tanda tangan digital, disimpan secara lokal di perangkat pengguna.

Penyimpanan Data

Data aplikasi disimpan secara lokal menggunakan penyimpanan perangkat, termasuk Room dan SharedPreferences. DokuFia tidak menyediakan akun pengguna dan tidak melakukan sinkronisasi otomatis atau pengunggahan data ke server.

File Excel dan PDF

DokuFia dapat membuat dan membaca file Excel (.xlsx) serta membuat laporan dan invoice dalam format PDF. File hanya dibuat, disimpan, atau dibagikan atas tindakan eksplisit pengguna melalui mekanisme pemilih file dan berbagi yang disediakan oleh sistem Android (Storage Access Framework).

Akses Perangkat

DokuFia tidak memerlukan izin penyimpanan khusus untuk fitur tersebut. Pemilihan file dilakukan melalui pemilih file sistem Android. Aplikasi hanya dapat mengakses file yang dipilih atau diberikan aksesnya oleh pengguna melalui mekanisme sistem tersebut.

Berbagi File

Jika pengguna memilih untuk membagikan file Excel atau PDF menggunakan aplikasi lain, file tersebut diberikan kepada aplikasi tujuan yang dipilih pengguna. Penggunaan atau pemrosesan file setelah diterima oleh aplikasi lain tunduk pada kebijakan privasi aplikasi atau layanan tersebut.

Layanan Online dan Pihak Ketiga

Versi DokuFia 1.0 tidak menyediakan sinkronisasi data pengguna ke server. Fitur Free Document berbasis template JSON/editor dokumen untuk sementara dinonaktifkan dan tidak ditawarkan kepada pengguna.

Anak-anak & Keluarga

DokuFia dapat digunakan oleh guru dan keluarga. Aplikasi tidak secara sengaja mengumpulkan atau mengirimkan data pribadi anak ke server. Jika pengguna memasukkan data siswa anak, data tersebut tetap disimpan secara lokal di perangkat pengguna.

Keamanan

DokuFia dirancang dengan pendekatan offline-first sehingga data utama aplikasi diproses dan disimpan secara lokal di perangkat. Pengguna tetap bertanggung jawab menjaga keamanan perangkat dan file yang diekspor atau dibagikan.

Perubahan Kebijakan

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Perubahan akan dipublikasikan di halaman ini dan tanggal pembaruan akan disesuaikan.

Privacy Policy — DokuFia (EN)

Last updated: 14 September 2026

DokuFia is an Android companion app for teachers to manage student data, daily attendance, monthly invoices, school profiles, and digital signatures.

Data Collection

DokuFia does not send users' personal data to the developer's servers. Information entered by users, including student names, classes, parent names, addresses, parent phone numbers, attendance records, invoice data, teacher names, school profile information, and digital signatures, is stored locally on the user's device.

Data Storage

Application data is stored locally using device storage, including Room and SharedPreferences. DokuFia does not require a user account and does not automatically synchronize or upload application data to a server.

Excel and PDF Files

DokuFia can create and read Excel (.xlsx) files and generate attendance reports and invoices in PDF format. Files are created, saved, or shared only through an explicit user action using Android's file picker and sharing mechanisms (Storage Access Framework).

Device Access

DokuFia does not require special storage permissions for these features. File selection is handled through the Android system file picker. The app can only access files that the user selects or grants access to through the system mechanisms.

File Sharing

If a user chooses to share an Excel or PDF file using another application, the file is provided to the application selected by the user. Any subsequent use or processing of the file is governed by the privacy policy of that application or service.

Online Services and Third Parties

DokuFia version 1.0 does not provide synchronization of user data to a server. The Free Document feature based on JSON templates and document editing is temporarily disabled and is not offered to users.

Children & Families

DokuFia may be used by teachers and families. The app does not knowingly collect or send children's personal data to a server. If a user enters data about a child student, that data remains stored locally on the user's device.

Security

DokuFia is designed with an offline-first approach, so the application's main data is processed and stored locally on the device. Users remain responsible for maintaining the security of their device and any files they export or share.

Changes

We may update this privacy policy from time to time. Changes will be published on this page and the update date will be revised accordingly.
