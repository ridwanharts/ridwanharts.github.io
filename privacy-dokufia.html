Kebijakan Privasi — DokuFia

Terakhir diperbarui: 14 September 2026

DokuFia adalah aplikasi Android untuk membuat dan mengedit dokumen atau materi siap cetak menggunakan template yang tersedia di aplikasi.

Data yang Dikumpulkan

Tidak ada. DokuFia tidak mengumpulkan, menyimpan, atau membagikan data pribadi pengguna untuk tujuan analitik atau pemasaran. Aplikasi tidak memerlukan akun pengguna.

Penggunaan Data dan Dokumen

Dokumen, desain, dan konten yang dibuat pengguna digunakan untuk menyediakan fungsi utama aplikasi. Data yang disimpan secara lokal di perangkat tetap berada di perangkat pengguna, kecuali pengguna secara sadar menggunakan fitur sistem Android untuk membagikan atau menyimpan file ke layanan lain.

Template dan Konten Online

DokuFia dapat mengambil data template dari sumber online untuk menyediakan atau memperbarui daftar template. Permintaan tersebut tidak digunakan oleh DokuFia untuk mengidentifikasi pengguna secara pribadi.

Izin Perangkat

DokuFia hanya menggunakan izin perangkat yang diperlukan untuk fitur yang tersedia. Jika pengguna memilih gambar atau file melalui pemilih file Android, akses tersebut dilakukan melalui mekanisme pemilih file yang disediakan oleh sistem Android.

Layanan Pihak Ketiga

DokuFia tidak menggunakan akun pihak ketiga atau layanan analitik untuk melacak aktivitas pengguna. Jika pengguna secara sadar membagikan atau mengunggah file menggunakan aplikasi atau layanan lain melalui fitur berbagi Android, penggunaan data selanjutnya tunduk pada kebijakan privasi layanan tersebut.

Anak-anak & Keluarga

DokuFia dapat digunakan oleh berbagai kelompok pengguna, termasuk anak-anak dengan pendampingan orang tua atau wali. DokuFia tidak secara sengaja mengumpulkan data pribadi anak-anak.

Keamanan

DokuFia dirancang untuk memproses data pengguna secara lokal sejauh diperlukan oleh fungsi aplikasi. Namun, tidak ada metode penyimpanan atau transmisi elektronik yang dapat dijamin 100% aman.

Perubahan Kebijakan

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Perubahan akan dipublikasikan di halaman ini dan tanggal pembaruan akan disesuaikan.

Privacy Policy — DokuFia (EN)

Last updated: 14 September 2026

DokuFia is an Android application for creating and editing printable documents or materials using available templates.

Data Collection

None. DokuFia does not collect, store, or share users' personal data for analytics or marketing purposes. The app does not require a user account.

Use of Data and Documents

Documents, designs, and content created by users are used to provide the app's core functionality. Data stored locally on the device remains on the user's device unless the user intentionally uses Android system features to share or save a file to another service.

Templates and Online Content

DokuFia may retrieve template data from online sources to provide or update its template catalog. These requests are not used by DokuFia to personally identify users.

Device Permissions

DokuFia only uses device access required for available features. When a user selects an image or file through the Android file picker, access is handled through the file picker provided by the Android system.

Third-Party Services

DokuFia does not use third-party accounts or analytics services to track user activity. If a user intentionally shares or uploads a file using another application or service through Android's sharing features, subsequent data use is governed by that service's privacy policy.

Children & Families

DokuFia may be used by different groups of users, including children under the guidance of a parent or guardian. DokuFia does not knowingly collect children's personal data.

Security

DokuFia is designed to process user data locally to the extent required by the app's functionality. However, no method of electronic storage or transmission can be guaranteed to be completely secure.

Changes

We may update this privacy policy from time to time. Changes will be published on this page and the update date will be revised accordingly.
